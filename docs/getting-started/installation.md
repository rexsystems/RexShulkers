---
title: Installation
description: Put RexShulkers on a Paper, Purpur, or Folia server.
sidebar:
  order: 1
---

1. Download the jar.
2. Put it in the server `plugins/` folder.
3. Start the server once so `plugins/RexShulkers/config.yml` and `shulkers.db` are written.
4. Edit `config.yml`.
5. Run `/rexshulkers reload`, or restart.

`/rexshulkers reload` reloads `config.yml` only. It does not close open shulkers and it does not delete `shulkers.db`.

PlaceholderAPI is not required. If it is installed when RexShulkers enables, the `%rexshulkers_...%` placeholders register on their own.
